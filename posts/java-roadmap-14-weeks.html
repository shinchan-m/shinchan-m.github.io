Java 后端实习路线：从 0 到 Offer 的 14 周冲刺计划

📅 2026-06-23  |  Java Roadmap Internship

江南大学 211 计算机大一升大二，目标 2027 年拿到第一份日常实习。这篇文章详细拆解 14 周冲刺计划的每一天——从 Java 基础到 AI Agent 部署。

暑假到了，大一刚结束的我决定：用 14 周时间，为自己打造一份有竞争力的 Java 后端简历。

为什么是 14 周？

6 月 23 日到 9 月 28 日，恰好是 14 周。江南大学的暑假就是这么长。如果每天投入 4 小时，14 周就是 392 小时——足够从入门到能面试的水平。

四维区分度策略

2026 年的 Java 初级岗竞争比已经达到 1:35+，光会写 CRUD 远远不够。我的策略是四个维度同时推进：

  1. 源码级理解：HashMap 怎么扩容？Spring Bean 生命周期有几级缓存？不只是背八股，而是看源码。
  2. AI Agent 差异化：95% 的候选人简历上没有 AI 项目。我用 LangChain4j + DeepSeek 做一个真正的 Agent 系统。
  3. 自研中间件：手写一个 ORM 框架和 RPC 框架，理解 MyBatis 和 Dubbo 的底层原理。
  4. 开源贡献：把自研项目开源到 GitHub，参与社区讨论。

14 周拆解

前 4 周打基础：Java 核心 + MySQL + 网络 + Spring Boot 入门。

中间 6 周深挖：Spring 源码 + JUC 并发 + JVM 调优 + 自研框架。

最后 4 周冲刺：AI Agent 系统 + Docker 部署 + 系统设计 + 简历打磨。

每天作息

09:00-11:50 学习理论，13:30-16:20 敲代码，16:30-17:30 运动，22:30 睡觉。周日休息——可持续才是王道。

这篇文章会持续更新，记录每一天的进度和踩坑。
